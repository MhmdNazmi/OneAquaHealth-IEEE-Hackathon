## 🌍 About the Project

**OneAquaHealth** is a collaborative citizen-science platform designed to make freshwater monitoring more accessible, engaging, and collaborative.

The platform connects the complete journey of environmental participation:

**🗺️ Explore → 🔎 Observe → 📚 Learn → 📤 Submit → 🤝 Collaborate → 🌊 Monitor**

Users can explore monitoring sites, record environmental observations, learn about aquatic ecosystems, contribute data, participate in community activities, and collaboratively analyze stream health.

# 🔬 Citizen Science Workflow

The platform connects the complete citizen-science journey:

### 🗺️ 1. Explore

Discover and access freshwater monitoring sites.

↓

### 🔎 2. Observe

Record environmental observations during site exploration.

↓

### 📚 3. Learn

Use educational content to better understand what is being observed.

↓

### 📤 4. Submit

Contribute observations and environmental data.

↓

### 🤝 5. Collaborate

Participate in challenges, discussions, publishing, and leaderboards.

↓

### 🌊 6. Monitor

Review updates and collaboratively analyze stream health.

# 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/MhmdNazmi/friendly-interface-builder/tree/main
cd friendly-interface-builder
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start the development server

```bash
npm run dev
```

Then open the local development URL shown in your terminal.

| Command              | Purpose                  |
